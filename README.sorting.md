# Sorting

## Bubble sorting

[coddy.tech визуализация](https://coddy.tech/visualize/ru/sorting/bubble-sort)

### ⚙️ Сложность

* Худший и средний случай: `O(n^2)`
* Лучший средний случай (с флагом): `O(n)`
* Память: `O(n)`

  Один из самых простых алгоритмов сортировки. Идея состоит в том, чтобы
  многократно проходить по массиву и сравнивать соседние элементы, меняя их
  местами, если они стоят в неправильном порядке.

Название "пузырек" появилось потому, что самые большие элементы буквально
"всплывают" к концу массива за каждый проход.

Представим массив `[5, 3, 8, 1]`, который мы хотим отсортировать по возрастанию.

**Проход 1:**

1. Сравниваем `5` и `3`. `5` > `3`, значит меняем местами -> `[3, 5, 8, 1]`
2. Сравниваем `5` и `8`. `5` < `8`, порядок правильный, не трогаем -> `[3, 5,
8, 1]`
3. Сравниваем `8` и `1`. `8` > `1`, меняем -> `[3, 5, 1, 8]`

После первого прохода самый большой элемент (`8`) оказался в конце пассива.
Теперь мы точно знаем, что последний элемент стоит на своем месте и **в
следующем проходе его можно не проверять**

**Проход 2:**

1. `3` и `5` — порядок верный -> `[3, 5, 1, 8]`
2. `5` и `1` — меняем -> `[3, 1, 5, 8]`

Теперь `5` на своем месте. Осталось разобраться с первыми двумя

**Проход 3:**

1. `3` и `1` — меняем -> `[1, 3, 5, 8]`

Готово. Массив отсортирован

### 💡Ключевые идеи

1. **Внешний цикл** — это количество проходов. На каждом проходе один элемент
   гарантированно встает на свое финальное месте. Значит, проходов нужно не
   больше, чем `n - 1`
2. **Внутренний цикл** — это сравнение соседних пар внутри прохода. Важный
   нюанс: с каждым проходом "хвост" массива, который уже отсортирован,
   растет. Поэтому внутренний цикл можно сокращать на количество уже
   сделанных проходов
3. Классический bubble sort делает все `n - 1` проходов, даже если массив
   уже отсортирован. Хорошей идеей будет завести флаг, который показывает,
   был ли хотя бы один обмен за текущий проход. Если обмена не было, то
   можно выйти из цикла

Классический bubble sort делает `n-1` проходов, даже если массив уже
отсортирован.
